# ParkFNB (public mirror of the old workspace)

This repository holds the early ParkFNB workspace, now arranged in the same folders as the team's main repository:

- `ai/`        space optimizer, and the ANPR research notes (the live ANPR service is developed elsewhere; see `ai/anpr/MOVED.md`)
- `hardware/`  ESP32 barrier firmware and hardware notes
- `research/`  studies, deck, status and hand-off documents
- `software/`  consumer, owner and admin apps, the landing page, the backend and the docs

Only material that was already public is kept here; it has been moved into this layout, not changed.
